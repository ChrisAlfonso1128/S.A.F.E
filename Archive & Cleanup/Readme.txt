# Archive & Cleanup Engine

## Overview
Develop the module responsible for safely archiving and removing files.

## Responsibilities
- Archive selected files into ZIP folders.
- Move files to the archive directory.
- Support safe deletion.
- Restore archived files if needed.
- Handle file operation errors.

## Deliverables
- Archive manager
- Delete/restore functions
- ZIP archive creation

# Call Code
- to call my code use
  archive.archive_files(files_to_archive)
  cleanup.move_to_trash(files_to_delete)
